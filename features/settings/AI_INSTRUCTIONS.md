# AI Scope & Boundary: Settings Feature

> **CRITICAL RULE FOR AI ASSISTANTS:**
> You are assigned to the **`feature/settings`** branch and the **`features/settings/`** folder.

### Allowed Actions:
- You may ONLY create, read, and modify files within `features/settings/`.
- Use the shared design tokens from `../../shared/style.css`.
- Keep preferences and settings toggles intuitive and reactive.

### Forbidden Actions:
- DO NOT modify files outside `features/settings/` (e.g., `login/`, `dashboard/`, `checkout/`, `index.html`).
- DO NOT edit `main` branch directly.

### Feature Specification:
- Account profile settings (Name, email address, password change shortcut).
- Preference toggles: Order SMS alerts, Promo emails, Dark mode.
- Interactive "Save Preferences" button with success toast.
